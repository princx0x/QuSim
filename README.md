# QuSim

A Quantum Circuit Simulator from Scratch.

## Progress so far

- NumPy/Matplotlib package `qusim` with single-qubit gates (I, X, Y, Z, H, S, T) plus Rx, Ry, Rz and the phase gate.
- State utilities for building |0…0⟩ and basis states, validating and applying gates, normalizing, and computing outcome probabilities.
- Measurement support: `sample()` for shot-count histograms and `measure()` for a single outcome with state collapse.
- Visualization of measurement counts and single-qubit states on the Bloch sphere.
- A pytest suite of 88 tests covering gates, states, measurement and plotting.

This project is under development, I will keep updating and making more commits to it in the coming days.
